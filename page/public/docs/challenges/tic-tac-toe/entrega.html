Entrega y evaluación

06.1

Entregables requeridos

Repositorio Git

  • Un repositorio con dos proyectos independientes: gato-server/ y gato-client/.
  • Cada proyecto es un Spring Boot independiente con su propio pom.xml.
  • README.md en la raíz con: instrucciones de ejecución, puertos, cómo levantar 2 instancias del cliente, y descripción de los requerimientos extendidos.
  • El código debe compilar y ejecutarse con mvn spring-boot:run sin configuración adicional.

Colección Postman

  • Colección exportada (.json) con todos los endpoints de ambos microservicios.
  • Una carpeta por microservicio (gato-server y gato-client).
  • Variables de entorno configuradas: {{serverUrl}}, {{client1Url}}, {{client2Url}}.
  • Ejemplos de request y response en cada endpoint, incluyendo al menos un caso de error por endpoint.
  • Una carpeta adicional con el flujo completo de una partida: crear, unirse, mover hasta el fin.

06.3

Consejos para un buen proyecto

Diseña antes de codear

Antes de escribir una línea de Java, diseña en papel los endpoints de ambos microservicios, los estados posibles de una partida y cómo el cliente mapea gameId a serverUrl. Un diseño claro evita refactorizaciones costosas.

Empieza por el server, luego el cliente

El server es autónomo. Impleméntalo y pruébalo directo con Postman antes de construir el cliente. Luego construye el cliente y prueba el flujo completo con dos instancias corriendo simultáneamente.

Prueba los fallos a propósito

Para probar el fallback: crea una partida apuntando al server, luego detén el server e intenta hacer un movimiento desde el cliente. La respuesta debe ser un 503 limpio, nunca un stack trace. Documenta este caso en Postman.

Prueba las dos instancias del cliente

El flujo completo debe funcionar con Postman apuntando a :8081 para las acciones del Jugador 1 y a :8082 para las del Jugador 2. Asegúrate de que las bases de datos MySQL de cada instancia sean independientes y que el docker-compose.yml las levante sin conflicto.

Fecha de entrega: Según el calendario publicado en el aula virtual. Se acepta entrega tardía con descuento de 1 punto por día hábil.
